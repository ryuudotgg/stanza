---
title: Release Binaries
description: Install Stanza without Bun on macOS or Linux.
---

Download a binary from the [latest release](https://github.com/ryuudotgg/stanza/releases/latest) to run Stanza without Bun. On Linux, pick the tab by libc. This names musl on a musl system, and glibc or GNU libc everywhere else:

```sh
ldd --version 2>&1 | head -n 1
```

<Tabs items={["macOS", "Linux (glibc)", "Linux (musl)"]}>
  <Tab value="macOS">
    | asset                 | machine       |
    | --------------------- | ------------- |
    | `stanza-darwin-arm64` | Apple silicon |
    | `stanza-darwin-x64`   | Intel         |

    ```sh
    asset=stanza-darwin-arm64 # use stanza-darwin-x64 on Intel
    cd "$(mktemp -d)"
    curl -fsSLO https://github.com/ryuudotgg/stanza/releases/latest/download/$asset
    curl -fsSLO https://github.com/ryuudotgg/stanza/releases/latest/download/SHA256SUMS
    grep " $asset\$" SHA256SUMS | shasum -a 256 -c &&
      mkdir -p ~/.local/bin &&
      install -m 755 $asset ~/.local/bin/stanza
    ```

    <Callout type="warn" title="Gatekeeper">
      A binary downloaded through a browser instead of curl carries the quarantine flag. The binaries are signed ad hoc, not notarized, so Gatekeeper stops them at launch. Clear the flag with `xattr -d com.apple.quarantine ~/.local/bin/stanza`.
    </Callout>

  </Tab>
  <Tab value="Linux (glibc)">
    | asset                | machine |
    | -------------------- | ------- |
    | `stanza-linux-x64`   | x64     |
    | `stanza-linux-arm64` | arm64   |

    ```sh
    asset=stanza-linux-x64 # use stanza-linux-arm64 on arm64
    cd "$(mktemp -d)"
    curl -fsSLO https://github.com/ryuudotgg/stanza/releases/latest/download/$asset
    curl -fsSLO https://github.com/ryuudotgg/stanza/releases/latest/download/SHA256SUMS
    grep " $asset\$" SHA256SUMS | sha256sum -c &&
      mkdir -p ~/.local/bin &&
      install -m 755 $asset ~/.local/bin/stanza
    ```

  </Tab>
  <Tab value="Linux (musl)">
    | asset                     | machine |
    | ------------------------- | ------- |
    | `stanza-linux-x64-musl`   | x64     |
    | `stanza-linux-arm64-musl` | arm64   |

    ```sh
    asset=stanza-linux-x64-musl # use stanza-linux-arm64-musl on arm64
    cd "$(mktemp -d)"
    curl -fsSLO https://github.com/ryuudotgg/stanza/releases/latest/download/$asset
    curl -fsSLO https://github.com/ryuudotgg/stanza/releases/latest/download/SHA256SUMS
    grep " $asset\$" SHA256SUMS | sha256sum -c &&
      mkdir -p ~/.local/bin &&
      install -m 755 $asset ~/.local/bin/stanza
    ```

    <Callout>
      Alpine leaves out curl and the C++ runtime. Install both with `apk add curl libstdc++`.
    </Callout>

  </Tab>
</Tabs>

The check prints `<asset>: OK`. Anything else means a damaged download, and the install does not run. Once `~/.local/bin` is on your `PATH`, run `stanza --version` to confirm the install.

The binary takes the same flags as the npm package.

<Callout type="info">There is no Windows binary. On Windows, use WSL with the Linux build.</Callout>
