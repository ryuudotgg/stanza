---
title: Existing Codebases
description: Hold new changes to the rules without reformatting old code.
---

In a repository whose existing code does not follow the rules, a hook that checks whole files flags code nobody touched, and a Stop pass rewrites it. `--hunks` narrows a run to the lines you changed, so new work follows the rules and old code stays as it is until someone edits it.

## Hooks

Add `--hunks` to the command in each hook:

<HookRegistration tab="Claude Code" title=".claude/settings.json" hunks />

<HookRegistration tab="Codex" title=".codex/hooks.json" hunks />

```sh tab="Pre-commit" title="pre-commit"
#!/bin/sh
exec stanza --check --staged --hunks
```

The Stop and SubagentStop passes, and the pass after each Write, Edit or Codex patch, then fix only around the lines changed against HEAD, and the pre-commit hook checks only the lines the commit changes.

## From the Command Line

```sh
stanza --check --changed --hunks
stanza --fix --changed --hunks
```

## What Counts as Changed

A gap between two statements is touched when a statement next to it, or a blank line in it, is on a changed line, and a rule applies only to a touched gap. Braces come off a body when the block holds a changed line or sits next to a touched gap. In a block of 2 or 3 statements that are compact after brace removal, a touched gap puts every statement in scope, even when the gap has no blank line. This widening does not apply at module top level or beside a statement that cannot be compact. [short-body](/rules/short-body#compact) defines compact. A file that is not tracked yet counts as changed throughout. Braces Stanza removed do not count as a change, so a second run changes nothing. The exact rules are under [Hunks](/reference/file-selection#hunks).

## Fixing Staged Lines

`--fix` has no staged line scope. When the pre-commit hook finds something in a file where only part of the file is in scope, it lists that file on stderr to fix by hand and restage with `git add -p`, instead of printing a command that would rewrite the whole file.

## Dropping --hunks

To bring the whole codebase in line at once, run `stanza --fix .` from its root, commit the result on its own, and remove `--hunks` from the hooks.
