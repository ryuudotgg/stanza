`stanza hook` runs as two Claude Code hooks: PostToolUse on Write, Edit and MultiEdit, and Stop. Add both to `.claude/settings.json`:

```json title=".claude/settings.json"
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit|MultiEdit",
        "hooks": [{ "type": "command", "command": "stanza hook" }]
      }
    ],
    "Stop": [{ "hooks": [{ "type": "command", "command": "stanza hook" }] }]
  }
}
```

An older registration with a PreToolUse entry for Write still runs, but that entry does nothing now, so replace it with the PostToolUse entry above.

## On Write and Edit

After a Write, Edit or MultiEdit lands, Stanza runs one `--fix` pass over the file it wrote. When that changes the file, the agent is told to read it again before editing it, so its next Edit matches what is on disk. The permission prompt and the Write result show the text as the agent sent it.

## On Stop

When the agent ends its turn, Stanza runs one `--fix` pass over the files the agent created or edited, read from the session transcript and the transcripts of its subagents and Workflow agents. A file the agent already committed is still checked, unless `--hunks` is set and the file has no change since HEAD. Files you left dirty stay untouched.

If the files come out clean, the agent sees nothing. If findings remain that `--fix` cannot apply, the turn does not end: the agent gets the findings grouped by file, each with its line and rule, fixes them, and replies again. The same message names every file Stanza rewrote, so the agent reads those again first.

## Flags

`--braces`, `--no-braces` and `--hunks` go in the command, as in `stanza hook --hunks`. In a repository whose existing code does not follow the rules yet, see [Existing Codebases](/guides/existing-codebases).

To turn the hooks off for one session, start Claude Code with `AGENT_HOOKS=0` in its environment.

## Errors

A bad flag or a git failure shows as a notice in Claude Code and never blocks the agent. [Hook Protocol](/reference/hook-protocol) has the full input, output and exit status of each event.
