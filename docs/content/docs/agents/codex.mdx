title: Codex
description: Fix every changed file when a Codex turn ends.

<Callout type="info">
  Codex runs a hook only after you trust it with `/hooks`, and a project hook also needs the project
  trusted. If your `hooks.json` already has a `hooks` object, add this entry to it.
</Callout>

<Callout type="warn">
  Stanza cannot read a Codex transcript, so it cannot tell which files Codex touched. The Stop pass
  fixes every changed file in the repository, including ones you edited by hand.
</Callout>

Codex runs `stanza hook` as a Stop hook. Put this in `~/.codex/hooks.json` for every repository, or in `.codex/hooks.json` at the root of one:

```json tab="Global" title="~/.codex/hooks.json"
{
  "hooks": {
    "Stop": [{ "hooks": [{ "type": "command", "command": "stanza hook" }] }]
  }
}
```

```json tab="Project" title=".codex/hooks.json"
{
  "hooks": {
    "Stop": [{ "hooks": [{ "type": "command", "command": "stanza hook" }] }]
  }
}
```

## On Stop

When Codex ends its turn, Stanza runs one `--fix` pass over the changed files in the repository. If findings remain that `--fix` cannot apply, the turn does not end: Codex gets the findings with a line per rule explaining it, fixes them, and replies again.

## No Format on Write

Codex fires PreToolUse and PostToolUse for `apply_patch`, but `stanza hook` formats only a Claude Code Write, so Codex edits are fixed when the turn ends. [Claude Code](/agents/claude-code) also formats each Write before it reaches disk.

## Flags

`--braces`, `--no-braces` and `--hunks` go in the command, as in `stanza hook --hunks`. In a repository whose existing code does not follow the rules yet, see [Existing Codebases](/guides/existing-codebases).

[Hook Protocol](/reference/hook-protocol) has the full input, output and exit status.
