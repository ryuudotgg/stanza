## Environment

`AGENT_HOOKS=0` turns the hook off.

`STANZA_WORKERS` sets the worker thread count. It accepts only digits representing an unsigned integer from 0 to 64 inclusive. `0` runs serially on the main thread, without worker threads. Any accepted value overrides the large-run threshold, even below 256 files.

Invalid or out-of-range values are ignored. Normal selection runs serially below 256 files and uses up to three worker threads at or above 256 files, depending on available parallelism.

`STANZA_RAW_TRANSFER=0` disables Oxc raw AST transfer and uses JSON transfer instead.

## Combining Flags

| combination                                                   | what happens                                        |
| ------------------------------------------------------------- | --------------------------------------------------- |
| neither `--fix` nor `--check`, or both                        | usage error                                         |
| none of paths, `--changed`, `--staged` and `--stdin`          | usage error, nothing to format                      |
| more than one of paths, `--changed`, `--staged` and `--stdin` | usage error                                         |
| `--staged` with `--fix`                                       | usage error, `--staged` works only with `--check`   |
| `--hunks` without `--changed` or `--staged`                   | usage error                                         |
| both `--braces` and `--no-braces`                             | usage error                                         |
| the same flag twice                                           | usage error                                         |
| a path that starts with `-`                                   | put `--` before it; everything after `--` is a path |

A usage error prints the problem and the usage on stderr and exits 2. `stanza hook` checks its own arguments and exits 1 instead, see [Hook Protocol](/reference/hook-protocol#exit-status).
