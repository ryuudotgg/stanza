## Environment

`AGENT_HOOKS=0` turns the hook off.

`STANZA_WORKERS` sets the worker thread count. It accepts only digits representing an unsigned integer from 0 to 64 inclusive. `0` runs serially on the main thread, without worker threads. Any accepted value applies at any file count, even below 64 files.

Invalid or out-of-range values are ignored. Without an accepted value, a run of fewer than 64 files is serial and a run of 64 files or more uses one worker thread fewer than the available parallelism, up to eight.

Runs over path arguments, `--changed` runs and `stanza hook` can use worker threads, under the same rule. `--staged` and `--stdin` never do.

These variables decide the [terminal form](/reference/output#in-a-terminal) and color:

| variable                                                                                      | effect                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NO_COLOR`                                                                                    | Any non-empty value turns color off on stdout and stderr. A terminal keeps its aligned layout.                                                                                                        |
| `TERM=dumb`                                                                                   | Turns color off as `NO_COLOR` does.                                                                                                                                                                   |
| `FORCE_COLOR`                                                                                 | Any value but empty or `0` colors piped stdout and stderr as a terminal would, in the one finding per line form. The stdout of `--json`, `--stdin`, explain, `--help` and the hook never takes color. |
| `CLAUDECODE`, `AI_AGENT`, `CODEX_SANDBOX`, `CODEX_THREAD_ID`, `CURSOR_AGENT` and `GEMINI_CLI` | Any of them non-empty marks a run under a coding agent: stanza prints one finding per line with no color, even on a terminal.                                                                         |

`NO_COLOR`, `TERM=dumb` and the agent variables each win over `FORCE_COLOR`.

## Combining Flags

| combination                                                   | what happens                                        |
| ------------------------------------------------------------- | --------------------------------------------------- |
| neither `--fix` nor `--check`, or both                        | usage error                                         |
| none of paths, `--changed`, `--staged` and `--stdin`          | usage error, nothing to format                      |
| more than one of paths, `--changed`, `--staged` and `--stdin` | usage error                                         |
| `--staged` with `--fix`                                       | usage error, `--staged` works only with `--check`   |
| `--hunks` without `--changed` or `--staged`                   | usage error                                         |
| both `--braces` and `--no-braces`                             | usage error                                         |
| the same flag twice                                           | usage error                                         |
| a path that starts with `-`                                   | put `--` before it; everything after `--` is a path |

A usage error prints the problem and a pointer to `stanza --help` on stderr and exits 2. A mistyped flag names the closest flag the command takes:

```text title="Usage Error"
stanza: unknown flag --chek, did you mean --check?
run `stanza --help` for usage
```

`stanza hook` checks its own arguments and exits 1 instead, see [Hook Protocol](/reference/hook-protocol#exit-status).
