## Install

Stanza is the npm package `@ryuugg/stanza`. The install pulls the native binary for your os, cpu and libc from one of its platform packages, such as `@ryuugg/stanza-darwin-arm64`.

<Tabs items={["npm", "Bun", "Release binary"]}>
  <Tab value="npm">

    ```sh
    npx @ryuugg/stanza --check src    # run once without installing
    npm i -g @ryuugg/stanza           # put stanza on your PATH
    ```

  </Tab>
  <Tab value="Bun">

    ```sh
    bunx @ryuugg/stanza --check src    # run once without installing
    bun add -g @ryuugg/stanza          # put stanza on your PATH
    ```

  </Tab>
  <Tab value="Release binary">
    Install a [release binary](/guides/release-binaries) to run Stanza without Node.js or Bun.
  </Tab>
</Tabs>

The binaries cover macOS and Linux. There is no Windows binary: run Stanza inside WSL.

## First Run

<Steps>
  <Step>
    ### Check

    Given this file at `src/publish.ts`:

    <include lang="ts" meta='title="src/publish.ts" lineNumbers'>
      ../../../tests/fixtures/after-guard/example.before.ts
    </include>

    `stanza --check src` reports what it would change, and changes nothing:

    ```text title="Output"
    src/publish.ts:3:3 after-guard add a blank line after the guard above, a new step starts here
    src/publish.ts:5:3 after-guard add a blank line after the guard above, a new step starts here
    ```

    It exits 1 when it finds something and 0 when the files are clean. [Output and Exit Codes](/reference/output) covers every line it can print.

  </Step>
  <Step>
    ### Fix

    `stanza --fix src` applies every rule it can decide on its own, in place:

    <DiffExample fixture="after-guard/example.ts" />

    Each guard now closes its step. A few rules only report, since fixing them needs a judgment Stanza leaves to you; [Rules](/rules) lists which.

  </Step>
  <Step>
    ### Check Again

    Run `stanza --check src` again. It prints nothing and exits 0.

  </Step>
</Steps>

## Run It Automatically

- [Claude Code](/agents/claude-code) formats each Write before it lands, each Edit right after, and the rest when a turn ends.
- [Codex](/agents/codex) fixes each file it patches, and every changed file when a turn ends, yours included.
- [Pre-Commit Hook](/guides/pre-commit) checks what is staged before each commit.
- [Editors](/guides/editors) formats a buffer on save.
- [Existing Codebases](/guides/existing-codebases) holds new changes to the rules without reformatting old code.
