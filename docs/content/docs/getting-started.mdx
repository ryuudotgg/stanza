## Install

Stanza is the npm package `@ryuugg/stanza`, and it runs on Bun 1.4 or later:

```sh
bunx @ryuugg/stanza --check src    # run once without installing
bun add -g @ryuugg/stanza          # put stanza on your PATH
```

The package needs Bun even when npm installs it. On a machine without Bun, running it through npm or npx formats nothing and prints one line naming what to install:

```text title="Without Bun"
stanza: needs Bun 1.4 or later (https://bun.sh) or a release binary (https://github.com/ryuudotgg/stanza/releases/latest)
```

To run Stanza without Bun, take a [release binary](/guides/release-binaries) instead.

## First Check

Given this file at `src/publish.ts`:

<include lang="ts" meta='title="src/publish.ts" lineNumbers'>
  ../../../tests/fixtures/after-guard/example.before.ts
</include>

`stanza --check src` reports what it would change, and changes nothing:

```text title="Output"
src/publish.ts:3:3 after-guard blank line expected after the guard above, the next statement starts a new step
src/publish.ts:5:3 after-guard blank line expected after the guard above, the next statement starts a new step
```

It exits 1 when it finds something and 0 when the files are clean. [Output and Exit Codes](/reference/output) covers every line it can print.

## First Fix

`stanza --fix src` applies every rule it can decide on its own, in place:

<include lang="ts" meta='title="src/publish.ts" lineNumbers'>
  ../../../tests/fixtures/after-guard/example.after.ts
</include>

Each guard now closes its step. Run `stanza --check src` again and it prints nothing. A few rules only report, since fixing them needs a judgment Stanza leaves to you; [Rules](/rules) lists which.
