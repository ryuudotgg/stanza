### 🎨 Changed file selection waits on git once per repository

`--changed`, `--changed --hunks` and the hook after an edit or at the end of a turn start the git calls that pick changed files together instead of one after another, and the repositories of one `Stop` start theirs at the same time. Each repository now waits about as long as one git process instead of three, and the files picked and everything printed stay the same.
