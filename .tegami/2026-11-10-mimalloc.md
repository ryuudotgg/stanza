### 🎨 Checks run faster, most of all on Alpine

The `stanza` binary now allocates memory through mimalloc on every platform, for about 130 KB more download. On Alpine and other musl systems a `--check` spread across worker threads no longer queues on the system allocator, so it runs about three times faster and keeps pace with the glibc build. On macOS a run takes about 15% less time. Every finding and fix is unchanged.
