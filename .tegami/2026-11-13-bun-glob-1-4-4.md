### 🐛 Line width overrides cover the files their formatter covers

An oxfmt, Prettier or Biome override now applies to exactly the files that formatter applies it to. `./src/*.ts` and `./src/**` match `src/a.ts`, while `./*.ts` matches only beside the config. Prettier's `?` and classes count UTF-16 code units and oxfmt's count bytes, so `?.ts` covers `é.ts` under Prettier and `??.ts` does under oxfmt. Prettier also matches a class by its literal spelling, so `app/[id]/page.tsx` covers that route file, and its `excludeFiles` follows Prettier's own name or path rule for each `files` pattern. A Biome include ending in `/` names folders only, as in Biome, so it neither covers nor excludes a file.
